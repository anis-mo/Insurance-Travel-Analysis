# ✈️Travel Insurance Insights Dashboard | Power BI

## 📌Project Overview

This project analyzes travel insurance data using Microsoft Power BI to explore insurance sales, commissions, claims, destinations, and policy duration.

The interactive dashboard provides key performance indicators (KPIs), visualizations, and slicers to help users explore travel insurance data and identify meaningful patterns.

## 🎯Objectives

- Analyze net sales and commission performance.
- Compare net sales across insurance agencies.
- Explore claims distribution by agency type.
- Identify the top 10 travel destinations.
- Analyze policies by product name.
- Understand the distribution of policies by duration.
- Build an interactive dashboard for data-driven analysis.

## 🧹Data Cleaning & Preparation

The dataset was prepared using Power Query in Microsoft Power BI through the following steps:

1. Data Inspection: Reviewed the dataset structure, column names, and data values to understand the available information.

2. Duplicate Check: Checked for duplicate records and removed duplicates where necessary.

3. Handling Missing Values: Identified blank values in text columns and replaced them with "Unknown" where appropriate.

4. Data Type Correction: Changed column data types to ensure that text, numeric, and other values were stored correctly.

5. Text Standardization: Reviewed text values to maintain consistent formatting across categorical columns.

6. Numeric Validation: Checked numeric columns for missing values and unusual or invalid values.

7. Negative Duration Check: Identified negative duration values and kept them in a separate category for further investigation rather than automatically deleting them.

8. Text Formatting: Standardized text values by converting them from uppercase to Proper Case, ensuring that the first letter of each word is capitalized for better readability and consistency (capitalized each word).

9. Final Data Validation: Reviewed the cleaned dataset to ensure it was ready for analysis and dashboard development.

## 🔎Analysis Questions

This project aims to answer the following questions:

1. How do net sales vary across different agencies?
2. How are claims distributed by agency type?
3. Which destinations have the highest number of policies?
4. Which insurance products are the most popular?
5. How are policies distributed across duration categories?
6. How do sales and policy patterns change when filtering by agency, destination, or product?

## 📊Key Performance Indicators (KPIs)

The dashboard includes four KPIs:

- Net Sales: Total net sales generated by travel insurance policies.
- Total Commission: Total commission value.
- Total Policies: Total number of insurance policies.
- Average Duration: Average duration of travel insurance policies in days.

## 📈Dashboard Visualizations

1. Net Sales by Agency

A horizontal bar chart comparing net sales across different insurance agencies.

2. Claims Distribution by Agency Type

A donut chart showing the distribution of claims across agency types, including Airlines and Travel Agency.

3. Top 10 Destinations

A bar chart highlighting the ten destinations with the highest number of insurance policies.

4. Policies by Product Name

A column chart comparing the number of policies across different insurance products.

5. Policies by Duration

A column chart showing the distribution of policies across duration categories:

- 1–30 Days
- 31–90 Days
- 91–180 Days
- 181–365 Days
- More than 365 Days
- Negative Duration

Negative duration records are displayed separately to make unusual values visible rather than mixing them with valid duration categories.

## 🎛️Interactive Slicers

The dashboard includes three slicers:

- Agency: Filter results by insurance agency.
- Destination: Explore specific travel destinations.
- Product Name: Filter results by insurance product.

These slicers allow users to interact with the dashboard and explore how results change across different selections.
